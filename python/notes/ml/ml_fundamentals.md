# ML Fundamentals

## Feature (X)

Input variables used to make predictions.

Examples:
- Age
- Experience
- House Size
- Bedrooms

---

## Target (y)

Output variable we want to predict.

Examples:
- Salary
- House Price
- Exam Score

---

## Supervised Learning

Input data and output labels are provided.

Examples:
- Salary Prediction
- House Price Prediction
- Spam Detection

---

## Unsupervised Learning

No target column exists.

Examples:
- Customer Segmentation
- Clustering

---

## Regression

Predicts a numerical value.

Examples:
- Salary
- House Price
- Temperature

---

## Classification

Predicts a category.

Examples:
- Spam / Not Spam
- Churn / No Churn
- Fraud / Not Fraud

---
