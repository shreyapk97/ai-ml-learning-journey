# Prefix and Suffix Pattern

Used in:
Product of Array Except Self

Goal:

nums = [1,2,3,4]

answer =

[
  24,
  12,
  8,
  6
]

Prefix:

prefix[i]
=
product of elements before i

Suffix:

suffix[i]
=
product of elements after i

Then:

answer[i]
=
prefix[i] * suffix[i]

Time:
O(n)

Space:
O(n)
