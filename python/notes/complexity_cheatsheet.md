# Complexity Cheat Sheet

Array Access
O(1)

Hash Map Lookup
O(1)

Set Lookup
O(1)

Sorting
O(n log n)

Nested Loops
O(n²)

Counter Frequency Count
O(n)

Two Pointers
O(n)

Binary Search
O(log n)

Rule:

Whenever you write a solution ask:

1. Can I replace nested loops?
2. Can a set help?
3. Can a dictionary help?
4. Is array sorted?
5. Can two pointers help?
